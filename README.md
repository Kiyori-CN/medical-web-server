# medical-web-server

Source workspace for the medical search web service at
`/srv/projects/medical-web-server`.

This repository contains the Flask backend, static frontend, public web assets,
documentation, and maintenance scripts. It intentionally excludes production
secrets, logs, caches, generated bytecode, and the large medical knowledge base.

Runtime data lives on the server:

- Environment file: `/etc/medical-exam.env`
- Knowledge base: `/srv/projects/medical-web-server/knowledge-base`
- Service: `medical-exam.service`
- Health: `http://127.0.0.1:8080/api/health`

Use `.env.example` as the non-secret configuration template.
