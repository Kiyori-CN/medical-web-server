# 医学题库与 AI 学习平台

把散落在 Excel、Word 中的题库整理成可检索、可练习、可回顾的学习工作台。
题目保留原文件路径、题号与内容版本；练习、收藏、错题和笔记按本地账号保存。

[样例体验](#无需私人题库的本地体验) · [项目展示](docs/showcase.md) · [功能与接口](docs/usage-reference.md) · [本地开发](docs/local-development.md)

## 核心能力

| 能力 | 实际用途 |
| --- | --- |
| 保留来源的题库 | 一份源文件对应一个题集；相似题可检索，原题答案差异仍保留 |
| 四种学习模式 | 练习、快刷、测试、背题；会话顺序固定，可恢复与复盘 |
| 关键词与智能检索 | SQLite FTS5 本地搜题；配置嵌入服务后可启用语义与混合检索 |
| 学习记录 | 收藏、错题、私有笔记、练习历史与个人数据导出 |
| 带引用的 AI 问答 | 按题库检索上下文回答，支持流式、停止与重新生成；需另配模型服务 |
| 本地账号与管理 | 权限、题库预检、设置、论坛及反馈；账号状态与题库事实分开保存 |

Flask 与原生 HTML/CSS/JavaScript 提供响应式界面，SQLite 保存题库和学习状态。
语义索引使用可选 NumPy mmap 矩阵，不要求独立向量数据库。

## 无需私人题库的本地体验

安装开发依赖后执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe scripts\run_demo.py
```

打开 `http://127.0.0.1:5091/`，自行创建仅供本次演示的管理员，再进入
“演示题库 → 平台入门 → 自编功能样例”体验目录、搜题、练习与收藏。

- 六道题均为自编平台操作样例，**不包含私人医学题库，也不是医学考试真题**。
- 仅监听本机；题库、账号和设置进入独立临时目录，正常退出后清理。
- 不读取已有 `data/`、`knowledge-base/`、`state/` 或模型密钥；演示不请求外部模型。
- AI 与语义检索保持未配置状态，不能将演示解释为真实模型问答验收。
- `--port 5092` 可更换端口；`--check` 只构建样例并检查健康接口，不启动监听。

## 使用自己的题库

将有权使用的原始文件放入本地 `data/`，按[本地开发](docs/local-development.md)构建并激活 catalog，
再启动真实工作区。构建器只读来源；部署和日常更新保留学习状态。
模型配置、语义索引与密钥处理见[设置指南](docs/settings-and-semantic-search.md)。

源文件、题库数据库、账号、私人笔记、模型密钥与生成索引不随本仓库公开。
仓库已有规模记录和详细 API 已移至[功能与接口参考](docs/usage-reference.md)，不能用六题演示推断真实数据规模或性能。

## 代表性研发工作

- 将规范题、来源文件、原题出现位置和内容版本分开建模，兼顾检索去重与原文件刷题。
- 将模式、题目顺序、草稿、交卷和复盘放在可恢复的账号会话中；测试交卷前由后端保护答案。
- 将 FTS/向量作为可重建索引，账号、题库和模型设置分别管理。
- 在原题上下文内接入带来源引用的 AI 会话，处理停止、断连和并发变更。

可结合[数据架构](docs/data-architecture.md)、[源码](app/backend/medical_app/)、[测试](tests/)和 Git 历史复核。
题库内容质量、AI 回答准确性与考试效果需要独立评估；本项目用于学习，不用于个体诊疗决策。
